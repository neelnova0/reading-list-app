Reading List App
A clean and simple reading-list app to keep track of books you want to read, are currently reading, and have finished.
Screenshot

Features
- Add books by entering a book title.
- Track reading status with three categories:
  - Want to Read
  - Reading
  - Finished
- Filter your collection by status or view all books.
- View reading statistics, including total books, currently reading, and finished books.
- Delete books from your list.
- Responsive card-based layout with a minimal, easy-to-use interface.

How to Use
1. Enter a book title in the input field.
2. Choose its starting status.
3. Select Add Book.
4. Change the status as you progress through the book.
5. Use the status filters to view books by reading stage.
6. Select Delete to remove a book from the list.

Project Goals
The app provides a straightforward way to organize a personal reading journey and see reading progress at a glance.
